A one-line loading-screen tip for stressed developers and AI coding agents: the bar isn't stuck, you're both just waiting for the other one to admit neither of you knows what the code does.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out node main.ts
```

This writes a single tip of at most 200 characters to `$MAKEFUN_OUTPUT_DIR/entry.txt`.
